# Calculator


A simple calculator written in Python that parses and evaluates basic mathematical expressions.

## Supported Operations
* **Addition** (`+`)
* **Subtraction** (`-`)
* **Multiplication** (`*`)
* **Division** (`/`)
* **Power** (`^`)

## Features
* **Flexible Input:** Accepts expressions in the format `x op y` (e.g., `5 + 3` or `2^10`).
* **Whitespace Insensitive:** Automatically removes spaces, making input formatting highly flexible.
* **Error Handling:** Includes basic handling for division by zero and invalid operators.

## How to Run
1. Copy the code from the `ent.py` file.
2. Paste it into your editor (e.g., VS Code, PyCharm).
3. Run the program.



# Kalkulačka

Jednoduchá kalkulačka napsaná v Pythonu, která zpracovává a vyhodnocuje základní matematické výrazy.

## Podporované operace
* **Sčítání** (`+`)
* **Odčítání** (`-`)
* **Násobení** (`*`)
* **Dělení** (`/`)
* **Mocnina** (`^`)

## Funkce
* **Flexibilní vstup:** Přijímá výrazy ve tvaru `x op y` (např. `5 + 3` nebo `2^10`).
* **Ignorování mezer:** Automaticky odstraňuje mezery, takže na formátování vstupu nezáleží.
* **Ošetření chyb:** Obsahuje základní ošetření pro dělení nulou a neplatné operátory.

## Jak spustit program
1. Zkopírujte kód ze souboru `ent.py`.
2. Vložte ho do svého editoru (např. VS Code, PyCharm).
3. Spusťte program.
